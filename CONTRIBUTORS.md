## Want your name here?

1.  Fork the repo and create a branch: `git checkout -b feat/add-contributor`.
2.  Edit `CONTRIBUTORS.md`.
3.  Make a meaningful change in a separate commit (one contributor per PR preferred).
4.  Open a PR with the description: *Add myself to contributors*. Link relevant issue/commit if applicable.
5.  Once approved, your name will be merged and the roster updated.

> Tip: prefer adding GitHub profile URL and a short role line (e.g., "UI, extension, docs"). If you prefer to remain anonymous, open an issue and the maintainers will add a pseudonym.
